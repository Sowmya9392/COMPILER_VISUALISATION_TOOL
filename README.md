**About the Project**

The Compiler Visualization Tool is an interactive web application designed to help students understand the internal working of a compiler. It allows users to enter source code and visualize how it is processed through different compilation phases.

**Features**

Lexical Analysis: Identifies keywords, identifiers, operators, and constants.

Token Visualization: Displays tokens in a structured format.

Symbol Table: Shows identifiers and their attributes.

Syntax Analysis: Checks source code against the defined grammar.

Abstract Syntax Tree (AST): Represents the hierarchical structure of the program.

Semantic Analysis: Detects semantic errors and type mismatches.

Intermediate Code Generation: Generates intermediate code representations.

Code Optimization: Demonstrates optimization and compares code before and after.

Target Code Generation: Displays the final generated code.
